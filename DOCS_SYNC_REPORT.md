## 2. Key Code Realities Discovered

1. **FastAPI Endpoints (Exact Count: 114):**
   - 110 route endpoints across 14 modules in `vista/backend/app/routes/` (`academics`: 23, `admin`: 29, `attendance`: 8, `auth`: 7, `dashboards`: 7, `enroll`: 2, `export`: 1, `lms`: 4, `mentor`: 6, `notifications`: 4, `reports`: 1, `risk`: 5, `student_portal`: 10, `students`: 3).
   - 4 system & monitoring endpoints in `main.py` (`/`, `/health`, `/metrics*`, `/ws/dashboard`).
   - Default backend port is **8002** (proxied from Vite frontend on 5173).

2. **Relational Database Schema (Exact Count: 24 Tables):**
   - 24 tables declared in `vista/backend/app/models/`: `access_requests`, `announcements`, `assignment_submissions`, `assignments`, `attendance`, `audit_logs`, `class_sections`, `classrooms`, `departments`, `interventions`, `mentor_assignments`, `notifications`, `parent_alerts`, `parent_contacts`, `risk_flags`, `schools`, `scores`, `semester_results`, `students`, `study_materials`, `subjects`, `teacher_subjects`, `timetable_slots`, `users`.

3. **User Roles (Exact Count: 6):**
   - `admin`, `hos` (Head of School), `hop` (Head of Program), `mentor`, `teacher`, `student`. All 6 roles have dedicated dashboards, navigation layouts, and backend RBAC route guards (`permissions.py`).

4. **Computer Vision Architecture & Verified Metrics:**
   - Face detection: SCRFD via InsightFace `buffalo_l`.
   - Feature extraction: ArcFace R50 (512-dimensional embedding). Default cosine threshold is **0.55** (`match.py`), configurable via `VISTA_FACE_MATCH_THRESHOLD`.
   - Personal Classifier: ResNet-50 PyTorch model (`personal_classifier.py` trained via `train_splitB.py`). Test accuracy is **90.10%** across 101 test samples on 20 student classes (`best_model_npz_splitB.pth`).
   - "100% accuracy" claim: Measured **only** on a small pilot set of 14 images representing 2 students (Saheel + Sujal).
   - Liveness anti-spoofing: Heuristic checks (`liveness.py`: confidence >= 0.5, face width >= 50px, Laplacian texture variance >= 20.0). MiniFASNet / Silent-FAS is NOT implemented (planned).
   - Multi-face tracking: Pure greedy IoU association matching in `tracker.py`. Docstring mentions Kalman/Hungarian, but no Kalman filter or Hungarian algorithm is implemented.

5. **Machine Learning & Risk Engine:**
   - 8 engineered features in `features.py` + 3 override flags (`consecutive_absences >= 7`, `attendance < 50%`, `internal_marks < 35%`).
   - Engagement formula: When assignment completion rate is `None`, engagement score equals `attendance_percentage` directly (not `0.5`).
   - XGBoost macro F1 = **0.957** is validated **exclusively on synthetic data** generated by `generate_sample_data.py`.
   - Explainability: Implemented via SHAP TreeExplainer in `vista/ml/explainer.py` alongside rule-based factor templates.
   - Automation: APScheduler runs in `scheduler.py` for automated daily risk recalculations at midnight.
