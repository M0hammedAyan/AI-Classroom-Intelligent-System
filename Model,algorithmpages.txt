How to show this during the presentation

Open the terminal (PowerShell) in the repo’s root.

Run a single command that prints the whole catalogue:

powershell
git grep -n "^def " vista/ml vista/vision | 
ForEach-Object {
    $file,$line,$rest = $_ -split ":",3
    $defName = $rest -replace "def (\w+).*", '$1'
    Write-Host "$file`t$defName`t$line"
}

This prints file   function   startLine – you can then scroll to the next def to see the end line (or use the table above).

Show a single function – e.g., the risk engine core:

powershell
Get-Content vista/ml/risk_engine.py -Raw |
Select-String -Pattern "def calculate_risk" -Context 0,30

The output displays the full method (lines 291‑316) together with its doc‑string, so the audience sees the exact algorithm you just described.

Explain the flow (high‑level):

Data → Features – features.compute_* extract numeric descriptors from the DB.
Scoring – _compute_component_scores → _weighted_sum → _score_to_level.
Explainability – explainer.explain_prediction (SHAP) and _generate_reasons.
Deployment – FastAPI endpoint (GET /coach/risk/{student_id}) calls calculate_risk.

Vision pipeline – Walk through the sequence:

detect.get_detector() → FaceDetector.detect() → extract_primary_face() → preprocess_face() → optional augment_face() → extract_embeddings_batch() → personal_classifier.classify_face() → match.match() → check_liveness().
