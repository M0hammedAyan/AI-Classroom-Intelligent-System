### 1. `test_task1_and_task2_all_7th_sem_subjects_visible`

**File:** `tests/test_audit_fixes.py` — `TestStudentPortalFixes.test_task1_and_task2_all_7th_sem_subjects_visible`

**Error:**
```
AssertionError: False is not true : Missing 7th sem subjects: {'22AIT703', '22AIU701', '22AIP706', '22AIT704C', '22AIU702'}
```

**Root cause:**
`conftest.py` (at `vista/backend/tests/conftest.py`) calls only `seed_demo_data(db)`. The 7th-semester subject rows (22AIU701, 22AIU702, 22AIT703, 22AIT704C, 22AIP706) are created inside `reconcile_current_roster(db)` in `vista/backend/app/db.py` (lines ~758–820). That second function is only called by the FastAPI `startup` event in `main.py`, not by `conftest.py`. Therefore, the test DB contains only the old DSA/ML/DBMS/CN/OS/SE subjects — never the 7th-sem ones.

**Type:** TEST BUG (conftest doesn't run full reconciliation) — but the seed logic itself also needs `reconcile_current_roster` to be idempotent and called after `seed_demo_data`.

**Fix:**
- `vista/backend/tests/conftest.py`, `setup_db` fixture — add `reconcile_current_roster(db)` after `seed_demo_data(db)`.

**Exact change:**
```python
# BEFORE (conftest.py setup_db):
    db = SessionLocal()
    seed_demo_data(db)
    db.close()

# AFTER:
    db = SessionLocal()
    seed_demo_data(db)
    from vista.backend.app.db import reconcile_current_roster
    reconcile_current_roster(db)
    db.close()
```

### 10. `test_mark_attendance_accepts_personal_model_result`

```
  File "vista/backend/app/routes/attendance.py", line 106
```

**Root cause:**
Production code calls `_call_vision(tmp_path, skip_liveness=True)` (attendance.py line 106). The test monkeypatches `_call_vision` with `lambda _path: {...}` — a 1-argument lambda that doesn't accept `skip_liveness`. When the production code passes `skip_liveness=True`, the call fails.

**Type:** TEST BUG — the lambda needs to accept and ignore `skip_liveness`.

**File:** `vista/backend/tests/test_personal_model_attendance.py`, `test_mark_attendance_accepts_personal_model_result`

**Exact change (lines ~20-29):**
```python
# BEFORE:
    monkeypatch.setattr(
        attendance,
        "_call_vision",
        lambda _path: {
            "student_id": "1DA22AI402",
            "confidence": 0.91,
            "liveness_passed": True,
        },
    )

# AFTER:
    monkeypatch.setattr(
        attendance,
        "_call_vision",
        lambda _path, skip_liveness=False: {
            "student_id": "1DA22AI402",
            "confidence": 0.91,
            "liveness_passed": True,
        },
    )
```
